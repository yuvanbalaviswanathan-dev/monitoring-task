# Monitoring Task

## Tech Stack

- AWS EC2
- Prometheus
- Grafana
- Node Exporter

## Objective

Install Prometheus and Grafana on an AWS EC2 instance.

Configure Node Exporter.

Connect Prometheus with Grafana.

Create a monitoring dashboard displaying system metrics.
